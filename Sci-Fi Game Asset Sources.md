# Sci-Fi Game Asset Sources

## Правила для IDE

- Сначала брать источники с `CC0` или максимально свободной лицензией.
- Для `Freesound`, `OpenGameArt`, `Sketchfab`, `itch.io` всегда проверять лицензию конкретного ассета.
- Сохранять рядом с файлом:
  - `source_url`
  - `license`
  - `author`
  - `download_date`
  - `attribution_required`
