# Space RPG Ursina Prototype

Небольшой 3D-прототип космической RPG на `Ursina Engine` с интерактивной картой галактики, диалогами и простым интерьером корабля.

## Статус проекта

Это **прототип / sandbox**, а не законченная игра и не полноценно упакованный production-проект.

Сейчас репозиторий поддерживает два режима запуска:

- **minimal fallback mode** — запуск из чистого клона без локально скачанных ассетов; используются примитивы и упрощённые визуальные замены;
- **enhanced mode** — тот же прототип, но с локально подготовленными внешними ассетами в `assets/external/` и локально сгенерированными текстурами в `assets/generated/`.

## Быстрый старт

```bash
python -m venv .venv
. .venv/Scripts/activate
pip install -r requirements.txt
python run_prototype.py
```

Прямой запуск `python space_rpg_prototype.py` тоже возможен, но **рекомендуемый entrypoint** — `run_prototype.py`: он создаёт ожидаемые папки проекта и печатает понятный статус по отсутствующим ассетам.

## Что работает уже сейчас

- тёмный космический фон;
- интерьер корабля из примитивов;
- `FirstPersonController`;
- пульт управления с `raycast`-взаимодействием;
- NPC / техник с веткой диалога;
- световой меч с простой анимацией;
- интерактивная карта галактики с выбором систем и прокладкой маршрута;
- локальная карта сектора с внутренними узлами.

## Управление

- `WASD` — движение
- `Мышь` — обзор
- `E` — взаимодействие с пультом / NPC
- `ЛКМ` — взмах световым мечом
- `ПКМ` на карте — панорамирование
- `Колесо мыши` на карте — масштаб
- `Enter` на карте — проложить курс
- `Esc` — пауза / назад / закрыть карту

## Структура репозитория

- `run_prototype.py` — рекомендуемая точка входа
- `space_rpg_prototype.py` — основной прототип сцены и UI
- `requirements.txt` — зависимости Python
- `Star.json` — описание цели и визуального направления карты
- `assets/README.md` — какие папки и ассеты ожидает проект
- `assets/external/` — внешние скачанные ассеты (необязательны для минимального запуска)
- `assets/generated/` — локально созданные текстуры / панели

## Внешние ассеты

Внешние пакеты **не обязательны**, но сильно улучшают картинку. Проект умеет переживать их отсутствие, однако в таком случае:

- часть NPC-моделей заменяется на простые формы;
- часть UI / фоновых текстур будет без специальных материалов;
- некоторые декоративные элементы карты и интерьера станут проще.

Список уже использованных и проверенных источников см. в `assets/SOURCES.md`.

## Текущее техническое ограничение

Сейчас почти весь прототип живёт в одном файле `space_rpg_prototype.py`. Это сознательно сохранено для быстрой итерации, но следующий полезный этап — разрезать проект на модули (`ui`, `windowing`, `scene`, `assets`, `npc`, `data`).

## Идея проекта

Фокус карты — не тяжёлое 3D-планетарное отображение, а **чистый holographic sci-fi UI** в духе `Mass Effect`: 2.5D-графика, маршруты, подсветка систем и хороший HUD-слой поверх данных.
