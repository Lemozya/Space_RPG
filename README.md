# Space RPG Ursina Prototype

Небольшой 3D-прототип космической RPG на `Ursina Engine`.

Полный путь проекта на этом компьютере:

`C:\Users\User\Desktop\Antigravity\space_rpg_ursina`

## Структура

- `space_rpg_prototype.py` - основной запускаемый файл.
- `requirements.txt` - минимальная зависимость для запуска.
- `assets/` - папка под модели, текстуры, звуки и внешние пакеты.
- `assets/external/Starter-Kit-FPS/` - локально скачанные ассеты Kenney.
- `assets/external/ursina_repo/` - локальный клон репозитория Ursina с текстурами и примерами.
- `assets/SOURCES.md` - памятка, откуда взялись ассеты и какие ссылки оказались нерабочими.

## Запуск

```bash
pip install -r requirements.txt
python space_rpg_prototype.py
```

## Управление

- `WASD` - движение
- `Мышь` - обзор
- `E` - взаимодействие с пультом
- `ЛКМ` - взмах световым мечом
- `ПКМ` на карте - панорамирование
- `Колесо мыши` на карте - масштаб
- `Enter` на карте - проложить курс
- `Esc` - закрыть карту
